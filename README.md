# জুয়েল টেলিকম — ই-সেবা পোর্টাল

NID ও খতিয়ান (ই-পর্চা) তথ্য অনুসন্ধান এবং PDF ডাউনলোডের ব্যক্তিগত পোর্টাল।

## 🚀 কীভাবে চালাবেন

```bash
node server.js
```

তারপর ব্রাউজারে খুলুন: **http://localhost:3000**

## 🔍 সার্চ সিস্টেম

- **নামের যেকোনো অংশ** লিখলেই ফলাফল আসবে — যেমন `ডালিম` লিখলে `হিমাংশু কুমার ডালিম` পাওয়া যাবে
- `মোঃ`, `মোছাঃ`, `মৃত` ইত্যাদি ছাড়াও খোঁজা যায়
- বাংলা/ইংরেজি দুই ভাষাতেই নাম খোঁজা যায় (যেমন: `HIMANGSHU`)
- NID নম্বর, গ্রাম, ইউনিয়ন — **যেকোনো ঘরে** তথ্য দিয়ে খোঁজা যায়
- **PDF আর্কাইভ সার্চ:** যেসব PDF-এর ডেটাবেজে রেকর্ড নেই, সেগুলোর টেক্সট PDF থেকে উদ্ধার করে আলাদা "📦 PDF আর্কাইভ" সেকশনে দেখানো হয়

## 📄 PDF → টেক্সট ইনডেক্স

- `pdfs/` ফোল্ডারের প্রতিটি PDF থেকে টেক্সট বের করে `js/pdf-text-index.js` ফাইলে রাখা হয়
- অ্যাডমিন প্যানেল থেকে আপলোড করলে সার্ভার **নিজে থেকেই** ইনডেক্স রিবিল্ড করে — আলাদা করে কিছু করতে হয় না
- হাতে নতুন PDF `pdfs/` ফোল্ডারে দিলে এই কমান্ড চালান:

```bash
node tools/build-pdf-text-index.js
```

> ℹ️ **নোট:** বর্তমানে `pdfs/` ফোল্ডারের PDF গুলো **নমুনা (mock) ফাইল**। আসল NID/পর্চার PDF বসিয়ে উপরের কমান্ডটি চালালে আসল টেক্সট দিয়ে ইনডেক্স তৈরি হয়ে যাবে।

## 📁 PDF বাল্ক আপলোড (খতিয়ান/ভোটার তালিকার PDF — একসাথে ১৫০টাও চলবে)

অ্যাডমিন প্যানেলে **"📥 বাল্ক ইমপোর্ট"** ট্যাবের নিচের দিকে **"PDF ফাইল বাল্ক আপলোড"** সেকশনে:

1. **সব PDF একসাথে সিলেক্ট করুন** (Ctrl+A)
2. **"⬆️ সব PDF আপলোড করুন"** চাপুন — ১০টা করে ব্যাচে আপলোড হবে
3. শেষে সারাংশ দেখাবে: কোন PDF-এ টেক্সট পাওয়া গেছে, কোনটা স্ক্যান করা

**এরপর কী হয়:**
- প্রতিটি PDF `pdfs/` ফোল্ডারে সেভ হয়
- প্রতিটি PDF থেকে **টেক্সট বের হয়ে সার্চ ইনডেক্সে** যোগ হয় (সাথে সাথে!)
- PDF-এর ভেতরের **যেকোনো নাম/শব্দ লিখে খুঁজলেই** সেই PDF আর্কাইভ ফলাফলে আসে — উদ্ধারকৃত টেক্সট + সম্ভাব্য ব্যক্তির নামসহ
- সম্ভাব্য নামগুলো **"👥 সম্ভাব্য ব্যক্তির নাম"** চিপ হিসেবে দেখায় — চিপে ক্লিক করলেই সার্চ হয়

**⚠️ স্ক্যান করা PDF (ছবি):** ভেতরে টেক্সট থাকে না বলে নাম বের করা সম্ভব নয়। সেগুলোর **ফাইলের নামে খতিয়ান নং/মৌজা/নাম রেখে দিন** (যেমন: `খতিয়ান-২৬-উত্তর-চাঁদখানা-হিমাংশু.pdf`) — ফাইলের নামেই খুঁজে পাওয়া যাবে।

**📦 সেটআপ:** ভালো মানের টেক্সট বের করার জন্য `pdf-parse` লাইব্রেরি ব্যবহৃত হয়:
```bash
npm install
```
(ইনস্টল না থাকলেও সহজ পদ্ধতিতে টেক্সট বের হবে — তবে `npm install` দিলে বাংলা টেক্সট আরও নিখুঁতভাবে আসবে)

## ✏️ PDF-এর সঠিক নাম বসানো (ভাঙা ফন্ট ঠিক করা)

কিছু PDF (বিশেষ করে ভোটার তালিকার eporcha PDF) থেকে নাম **ভাঙা অক্ষরে** আসে
(ফন্ট এনকোডিংয়ের কারণে — যেমন `sরীফা` দেখায়, আসলে `শরীফা`)।

**কিন্তু এতে সমস্যা নেই — ভোটার নং, এলাকা কোড দিয়ে খোঁজা ঠিকঠাক কাজ করে!**

আর নামে খুঁজতে চাইলে: অ্যাডমিন প্যানেল → **"📥 বাল্ক ইমপোর্ট"** ট্যাব →
**"✏️ PDF-এর সঠিক নাম বসানো"** সেকশনে:

1. PDF ফাইল বেছে নিন
2. সঠিক নামগুলো লিখুন (এক লাইনে এক নাম)
3. **"💾 নামের তালিকা সেভ করুন"** চাপুন

সেভ করা নামগুলো **সবুজ চিপ** হিসেবে কার্ডে দেখাবে এবং সেগুলো দিয়ে নিখুঁতভাবে সার্চ হবে।

## 📥 বাল্ক ইমপোর্ট (একসাথে হাজারো রেকর্ড)

অ্যাডমিন প্যানেলে **"📥 বাল্ক ইমপোর্ট"** ট্যাবে গিয়ে:

1. **ভোটার/NID তালিকা** বা **খতিয়ান তালিকা** বেছে নিন
2. CSV ফাইল আপলোড করুন অথবা টেক্সট পেস্ট করুন (প্রথম লাইনে হেডার)
3. **"ইমপোর্ট করুন"** চাপুন — সব রেকর্ড সার্ভারে সেভ হয়ে সাথে সাথে সার্চেবল হয়

**CSV হেডার (ইংরেজি):**
- NID: `sl,name,name_en,nid,father,mother,dob,village,union,post,upazila,district,occupation,gender`
- খতিয়ান: `khatian_no,dag_no,owner,father,mouza,jl_no,upazila,district,division,land_type,area,search_text`

বাংলা হেডারও চলে (নাম, পিতা, মাতা, গ্রাম ইত্যাদি)। ডুপ্লিকেট রেকর্ড অটো বাদ পড়ে।

> 💡 **বড় ভোটার তালিকার জন্য:** Excel ফাইল থাকলে সেটা CSV হিসেবে সেভ করে আপলোড করুন। চাইলে ফাইলটা আমাকে পাঠিয়ে দিলেও আমি সরাসরি ওয়েবসাইটে বসিয়ে দিতে পারবো।

## 📤 অ্যাডমিন থেকে আপলোড (নতুন!)

অ্যাডমিন প্যানেলের ফর্ম দিয়ে রেকর্ড + PDF আপলোড করলে:

- **রেকর্ডটি সার্ভারে স্থায়ীভাবে সেভ হয়** (`js/data-uploads.js`) — পেজ রিফ্রেশ করলেও হারায় না
- **PDF ফাইলটি `pdfs/` ফোল্ডারে সেভ হয়**
- **PDF থেকে টেক্সট বের হয়ে সার্চ ইনডেক্সে যোগ হয়** — সাথে সাথেই সেই নামে সার্চ করা যায়

**স্ক্যান করা খতিয়ানের জন্য:** ছবি হিসেবে স্ক্যান করা PDF থেকে লেখা বের করা যায় না। তাই খতিয়ান ফর্মের
**"খতিয়ানে থাকা অন্যান্য নাম / Search Keywords"** ঘরে খতিয়ানের ভেতরের নামগুলো লিখে দিন (কমা দিয়ে আলাদা করে) —
এই নামগুলো দিয়েই পরে সার্চ করা যাবে।

## ➕ নতুন রেকর্ড যোগ করা

1. অ্যাডমিন প্যানেলে লগইন করুন
2. "🆔 ভোটার / NID তথ্য আপলোড" অথবা "📄 ই-পর্চা / খতিয়ান তথ্য আপলোড" ট্যাব বেছে নিন
3. ফর্ম পূরণ করে (চাইলে PDF-ও আপলোড করে) সেভ করুন
4. Firebase কনফিগার করা থাকলে ক্লাউডে সেভ হয়, না হলে লোকাল ডেটাবেজে (`js/data.js`) সেভ হয়

## 🗂️ ফাইল কাঠামো

```
index.html           → মূল পোর্টাল
admin.html           → অ্যাডমিন প্যানেল
server.js            → লোকাল সার্ভার
js/data.js           → NID ও খতিয়ান ডেটা
js/pdf-text-index.js → PDF থেকে উদ্ধারকৃত টেক্সট ইনডেক্স (অটো-জেনারেটেড)
js/app.js            → সার্চ ও রেন্ডারিং লজিক
js/admin.js          → অ্যাডমিন লজিক
tools/build-pdf-text-index.js → PDF → টেক্সট ইনডেক্স জেনারেটর
pdfs/                → সব PDF ফাইল
```
