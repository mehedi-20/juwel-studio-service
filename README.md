# জুয়েল টেলিকম — ই-সেবা পোর্টাল

NID ও খতিয়ান (ই-পর্চা) তথ্য অনুসন্ধান এবং PDF ডাউনলোডের ব্যক্তিগত পোর্টাল।


## 🔍 সার্চ সিস্টেম

- **নামের যেকোনো অংশ** লিখলেই ফলাফল আসবে — যেমন `রহিম` লিখলে `মোঃ রহিম মিয়া`-র মতো নাম পাওয়া যাবে
- `মোঃ`, `মোছাঃ`, `মৃত` ইত্যাদি ছাড়াও খোঁজা যায়
- বাংলা/ইংরেজি দুই ভাষাতেই নাম খোঁজা যায় (যেমন: `RAHIM`)
- NID নম্বর, গ্রাম, ইউনিয়ন — **যেকোনো ঘরে** তথ্য দিয়ে খোঁজা যায়
- **PDF আর্কাইভ সার্চ:** যেসব PDF-এর ডেটাবেজে রেকর্ড নেই, সেগুলোর টেক্সট PDF থেকে উদ্ধার করে আলাদা "📦 PDF আর্কাইভ" সেকশনে দেখানো হয়

## 📄 PDF → টেক্সট ইনডেক্স

- `pdfs/` ফোল্ডারের প্রতিটি PDF থেকে টেক্সট বের করে `js/pdf-text-index.js` ফাইলে রাখা হয়
- অ্যাডমিন প্যানেল থেকে আপলোড করলে সার্ভার **নিজে থেকেই** ইনডেক্স রিবিল্ড করে — আলাদা করে কিছু করতে হয় না
- হাতে নতুন PDF `pdfs/` ফোল্ডারে দিলে এই কমান্ড চালান:

```bash
node tools/build-pdf-text-index.js
```

> ℹ️ **নোট:** `pdfs/` ফোল্ডারে শুধু আপলোডকৃত আসল PDF-গুলো থাকে (ডেমো/নমুনা ফাইল সরিয়ে ফেলা হয়েছে)। নতুন PDF যোগ করলে উপরের কমান্ডটি চালান।

## 📁 PDF বাল্ক আপলোড (খতিয়ান/ভোটার তালিকার PDF — একসাথে ১৫০টাও চলবে)

অ্যাডমিন প্যানেলে **"📥 বাল্ক ইমপোর্ট"** ট্যাবের নিচের দিকে **"PDF ফাইল বাল্ক আপলোড"** সেকশনে:

1. **সব PDF একসাথে সিলেক্ট করুন** (Ctrl+A)
2. **"⬆️ সব PDF আপলোড করুন"** চাপুন — ১০টা করে ব্যাচে আপলোড হবে
3. শেষে সারাংশ দেখাবে: কোন PDF-এ টেক্সট পাওয়া গেছে, কোনটা স্ক্যান করা

**এরপর কী হয়:**
- প্রতিটি PDF `pdfs/` ফোল্ডারে সেভ হয়
- প্রতিটি PDF থেকে **টেক্সট বের হয়ে সার্চ ইনডেক্সে** যোগ হয় (সাথে সাথে!)
- PDF-এর ভেতরের **যেকোনো নাম/শব্দ লিখে খুঁজলেই** সেই PDF আর্কাইভ ফলাফলে আসে — উদ্ধারকৃত টেক্সট + সম্ভাব্য ব্যক্তির নামসহ
- সম্ভাব্য নামগুলো **"👥 সম্ভাব্য ব্যক্তির নাম"** চিপ হিসেবে দেখায় — চিপে ক্লিক করলেই সার্চ হয়

**⚠️ স্ক্যান করা PDF (ছবি):** ভেতরে টেক্সট থাকে না বলে নাম বের করা সম্ভব নয়। সেগুলোর **ফাইলের নামে খতিয়ান নং/মৌজা/নাম রেখে দিন** (যেমন: `খতিয়ান-২৬-উত্তর-চাঁদখানা-রহিম.pdf`) — ফাইলের নামেই খুঁজে পাওয়া যাবে।

**📦 সেটআপ:** ভালো মানের টেক্সট বের করার জন্য `pdf-parse` লাইব্রেরি ব্যবহৃত হয়:
```bash
npm install
```
(ইনস্টল না থাকলেও সহজ পদ্ধতিতে টেক্সট বের হবে — তবে `npm install` দিলে বাংলা টেক্সট আরও নিখুঁতভাবে আসবে)

## 🤖 AI দিয়ে PDF পড়া (Groq / Gemini) — প্রধান পদ্ধতি

**OCR আর লাগবে না — AI নিজেই পুরো PDF পড়ে দেয়।**
Tesseract OCR বাংলা লেখায় প্রায়ই ভুল করত (নাম ভাঙা আসা, জন্ম তারিখ পেশার ঘরে ঢোকা ইত্যাদি)।
এখন PDF-এর পেজগুলো AI-কে পাঠানো হয় — AI ভোটার তালিকা বুঝে পড়ে **সাজানো JSON** (নাম, ভোটার নং, পিতা, মাতা, জন্ম তারিখ, ঠিকানা) ফেরত দেয়। ভুল প্রায় থাকে না, আর সার্চ আগের মতোই **instant** থাকে।

দুই AI প্রোভাইডার চলে (অ্যাডমিন প্যানেল থেকে বাছাই):
- **⚡ Groq** (ডিফল্ট) — [console.groq.com/keys](https://console.groq.com/keys) থেকে ফ্রি key; Llama-4 vision মডেল পেজের ছবি পড়ে; খুব দ্রুত
- **🌐 Google Gemini** — [aistudio.google.com](https://aistudio.google.com/app/apikey) থেকে ফ্রি key; PDF সরাসরি যায়

### একবারের সেটআপ (২ মিনিট)

1. ফ্রি API key নিন (উপরের লিংক থেকে)
2. অ্যাডমিন প্যানেল → **"📥 বাল্ক ইমপোর্ট"** ট্যাব → **"🤖 AI দিয়ে পড়ুন"** সেকশনে key পেস্ট করে **💾 সেভ** → **✅ পরীক্ষা** চাপুন
3. Key সার্ভারে `ai-config.json` ফাইলে সেভ থাকে (`.gitignore`-এ দেওয়া, তাই Git-ে যায় না)

### PDF পড়ানো (আপলোডের পর একবারই)

- **"⚡ বাকি সব PDF AI দিয়ে পড়ুন"** — যেগুলো এখনো পড়া হয়নি সব কিউতে যাবে (ব্যাকগ্রাউন্ডে)
- অথবা স্ট্যাটাস টেবিলে প্রতিটি বাকি PDF-এর পাশে **"🤖 AI পড়ুন"** বাটন
- **"🔄 আবার (AI)"** বাটন — আগে OCR-এ পড়া কোনো PDF-এ ভুল তথ্য থাকলে AI দিয়ে আবার পড়ে **ঠিক করে দেয়** (পুরনো ভুল এন্ট্রি মুছে নতুন বসে)
- কোটা শেষ হলে স্পষ্ট বার্তা দেখায় — কিছুক্ষণ পর আবার চালালেই বাকিগুলো পড়বে

**🛡️ Duplicate সুরক্ষা:** একবার যে PDF পড়া হয়ে গেছে (AI বা OCR) সেটা আবার পড়া হয় না। "🔄 আবার (AI)" বাটনেই জোর করে আবার পড়ানো যায়।

## 🔎 সার্চের সময় AI খোঁজা — "AI দিয়ে খুঁজুন" (নতুন!)

মূল সাইটে কিছু খুঁজে **কিছুই না পেলে** ফলাফলের জায়গায় **"🤖 AI দিয়ে খুঁজুন"** বাটন দেখায়।
চাপলে সার্ভার আপনার আপলোড করা **সব PDF-এর প্রতিটি পেজ ছবি বানিয়ে AI-এর চোখে স্ক্যান করে**
নাম/ভোটার নং/NID মিলিয়ে ব্যক্তির পূর্ণ তথ্য (নাম, পিতা, মাতা, জন্ম তারিখ, ঠিকানা + কোন PDF-এর কোন পেজে আছেন) এনে দেয়:

- লাইভ প্রগ্রেস দেখায় ("পেজ ৪০/১৪০০ পড়া হচ্ছে...") — চাইলে **বন্ধ করুন** লিংক
- নামের আংশিক মিলও ধরে ("রহিম" দিলে "মোঃ রহিম মিয়া" পাবেন); নাম + পিতার নাম একসাথে দিলে আরও নিখুঁত
- যে তালিকায় পেয়ে যায়, সেখানেই থেমে যায় (দ্রুততর)
- খতিয়ান ট্যাবেও চলে — মালিকের নাম/খতিয়ান নং PDF থেকেই খুঁজে দেয়
- আগে যেসব PDF "AI দিয়ে পড়ুন"-এ পড়া হয়ে গেছে সেগুলো তো instant সার্চেই পাওয়া যায় — এই বাটন প্রধানত নতুন/না-পড়া PDF-এর জন্য

### কনফিগ ফাইল (`ai-config.json` — ঐচ্ছিক, অ্যাডমিন প্যানেল থেকেই সব হয়)

```json
{
  "provider": "groq",
  "api_key": "gsk_...",
  "model": "meta-llama/llama-4-scout-8b-17e-instruct",
  "chunk_pages": 25,
  "request_interval_ms": 2500,
  "groq_pages": 3,
  "find_pages": 4
}
```

CLI দিয়ে হাতে চালাতে চাইলে:
```bash
node tools/ai-extract-voters.mjs pdfs/730659_com_1279_female_without_photo_72_2025-11-24.pdf --save
node tools/ai-find-person.mjs "মোঃ রহিম মিয়া"
```

## 🔍 পুরনো OCR (Tesseract) — ব্যাকআপ

AI কোনো কারণে কাজ না করলে (key নেই, ইন্টারনেট নেই) তখনই OCR ব্যাকআপ হিসেবে আছে —
অ্যাডমিন প্যানেলের নিচের **"🔍 পুরনো OCR (Tesseract)"** ফোল্ডারটি খুলে চালান। প্রতি PDF-এ ৩-৫ মিনিট লাগে ও বাংলা নামে কিছু ভুল থাকতে পারে। প্রয়োজনীয় প্যাকেজ: `npm install` (mupdf, tesseract.js, @tesseract.js-data/ben)।

**📄 ই-পর্চা/খতিয়ান PDF:** ওগুলো সাধারণত ছবি-ভিত্তিক, আর ভোটার তালিকার মতো নির্দিষ্ট ফরম্যাটের না — তাই AI/OCR দিয়ে সঠিকভাবে নাম বের করা যায় না। সবচেয়ে ভালো উপায়:
1. অ্যাডমিন প্যানেল → **"📄 ই-পর্চা / খতিয়ান তথ্য আপলোড"** ট্যাবে খতিয়ান নং/মৌজা/মালিকের নাম লিখে PDF-সহ সেভ করুন → সাথে সাথে সার্চে আসবে
2. অথবা **"📥 বাল্ক ইমপোর্ট" → "PDF ফাইল বাল্ক আপলোড"** দিয়ে অনেকগুলো পর্চা PDF দিন (টেক্সট-লেয়ার থাকলে স্বয়ংক্রিয়ভাবে সার্চযোগ্য হয়)

## ✏️ PDF-এর সঠিক নাম বসানো (ভাঙা ফন্ট ঠিক করা)

কিছু PDF (বিশেষ করে ভোটার তালিকার eporcha PDF) থেকে নাম **ভাঙা অক্ষরে** আসে
(ফন্ট এনকোডিংয়ের কারণে — যেমন `sরীফা` দেখায়, আসলে `শরীফা`)।

**কিন্তু এতে সমস্যা নেই — ভোটার নং, এলাকা কোড দিয়ে খোঁজা ঠিকঠাক কাজ করে!**

আর নামে খুঁজতে চাইলে: অ্যাডমিন প্যানেল → **"📥 বাল্ক ইমপোর্ট"** ট্যাব →
**"✏️ PDF-এর সঠিক নাম বসানো"** সেকশনে:

1. PDF ফাইল বেছে নিন
2. সঠিক নামগুলো লিখুন (এক লাইনে এক নাম)
3. **"💾 নামের তালিকা সেভ করুন"** চাপুন

সেভ করা নামগুলো **সবুজ চিপ** হিসেবে কার্ডে দেখাবে এবং সেগুলো দিয়ে নিখুঁতভাবে সার্চ হবে।

## 📥 বাল্ক ইমপোর্ট (একসাথে হাজারো রেকর্ড)

অ্যাডমিন প্যানেলে **"📥 বাল্ক ইমপোর্ট"** ট্যাবে গিয়ে:

1. **ভোটার/NID তালিকা** বা **খতিয়ান তালিকা** বেছে নিন
2. CSV ফাইল আপলোড করুন অথবা টেক্সট পেস্ট করুন (প্রথম লাইনে হেডার)
3. **"ইমপোর্ট করুন"** চাপুন — সব রেকর্ড সার্ভারে সেভ হয়ে সাথে সাথে সার্চেবল হয়

**CSV হেডার (ইংরেজি):**
- NID: `sl,name,name_en,nid,father,mother,dob,village,union,post,upazila,district,occupation,gender`
- খতিয়ান: `khatian_no,dag_no,owner,father,mouza,jl_no,upazila,district,division,land_type,area,search_text`

বাংলা হেডারও চলে (নাম, পিতা, মাতা, গ্রাম ইত্যাদি)। ডুপ্লিকেট রেকর্ড অটো বাদ পড়ে।

> 💡 **বড় ভোটার তালিকার জন্য:** Excel ফাইল থাকলে সেটা CSV হিসেবে সেভ করে আপলোড করুন। চাইলে ফাইলটা আমাকে পাঠিয়ে দিলেও আমি সরাসরি ওয়েবসাইটে বসিয়ে দিতে পারবো।

## 📤 অ্যাডমিন থেকে আপলোড (নতুন!)

অ্যাডমিন প্যানেলের ফর্ম দিয়ে রেকর্ড + PDF আপলোড করলে:

- **রেকর্ডটি সার্ভারে স্থায়ীভাবে সেভ হয়** (`js/data-uploads.js`) — পেজ রিফ্রেশ করলেও হারায় না
- **PDF ফাইলটি `pdfs/` ফোল্ডারে সেভ হয়**
- **PDF থেকে টেক্সট বের হয়ে সার্চ ইনডেক্সে যোগ হয়** — সাথে সাথেই সেই নামে সার্চ করা যায়

**স্ক্যান করা খতিয়ানের জন্য:** ছবি হিসেবে স্ক্যান করা PDF থেকে লেখা বের করা যায় না। তাই খতিয়ান ফর্মের
**"খতিয়ানে থাকা অন্যান্য নাম / Search Keywords"** ঘরে খতিয়ানের ভেতরের নামগুলো লিখে দিন (কমা দিয়ে আলাদা করে) —
এই নামগুলো দিয়েই পরে সার্চ করা যাবে।

## ➕ নতুন রেকর্ড যোগ করা

1. অ্যাডমিন প্যানেলে লগইন করুন
2. "🆔 ভোটার / NID তথ্য আপলোড" অথবা "📄 ই-পর্চা / খতিয়ান তথ্য আপলোড" ট্যাব বেছে নিন
3. ফর্ম পূরণ করে (চাইলে PDF-ও আপলোড করে) সেভ করুন
4. Firebase কনফিগার করা থাকলে ক্লাউডে সেভ হয়, না হলে লোকাল ডেটাবেজে (`js/data.js`) সেভ হয়

## 🗂️ ফাইল কাঠামো

```
index.html           → মূল পোর্টাল (সার্চে কিছু না পেলে "🤖 AI দিয়ে খুঁজুন" বাটন)

js/app.js            → সার্চ ও রেন্ডারিং লজিক (AI-খোঁজাসহ)

pdfs/                → সব PDF ফাইল
```
